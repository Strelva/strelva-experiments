# Research a Buffalo property

## Who this helps

Buffalo residents, tenants, owners, block clubs, reporters, and community
groups who need a grounded starting point for one parcel or a small set of
parcels.

## Immediate-use workflow

Use the address and, when available, the Erie County section-block-lot (SBL) as
the join key. Start with the county parcel and tax records, then compare the
City property card, permits, code violations, rental registration, and any
environmental or flood context. Save the source URL, observed date, matching
address/SBL, and the exact field or sentence that supports each observation.
Use the worksheet in `SKILL.md` to label a vacancy signal as a signal, not a
finding.

## Limits

Public parcel, permit, inspection, and rental data can lag, omit records, use
different identifiers, or contain corrections. A missing violation, permit,
rental registration, or owner match does not prove that none exists. Maps are
not surveys. Ownership, liens, title, occupancy, code compliance, flood risk,
and environmental status require confirmation from the responsible office or a
qualified professional.

This pack does not identify a property as vacant or unsafe and does not provide
legal, tax, housing, engineering, or environmental advice.

## Update method

Review every URL and dataset landing page quarterly and before publishing a
claim. Re-run the workflow on one known address, note changed field names or
definitions, and update `sources.json`, `pack.json` `reviewedAt`, and this file
when the method or limits change. Preserve the previous observation date in
your research log instead of overwriting it.
