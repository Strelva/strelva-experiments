# Public skill names

Name every published skill for the task a Buffalo user can complete. The folder,
frontmatter name, interface display name, documentation heading, and Labs title
must describe the same action.

The official skill titles are:

- Find Buffalo Business Help
- Research a Buffalo Property
- Follow a Buffalo Public Decision
- Understand a Buffalo Notice

Do not use packaging terms such as navigator, sources, evidence, or case as the
primary name when a direct user action is clearer.
